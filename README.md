# АвтоПро — шаблон лендинга автосервиса

Тёмный «премиум» лендинг для автосервиса: цепляющий первый экран, анимации, запись онлайн. Проект работает и как витрина портфолио, и как **шаблон для быстрой переделки под нового клиента** — весь контент живёт в одном файле `js/config.js`.

## Стек и структура

Чистый HTML + CSS + JavaScript. **Нулевые зависимости** — никаких сборщиков, npm и фреймворков. Хостить можно где угодно (любой статический хостинг, GitHub Pages, Netlify, Vercel).

```
index.html      — разметка (12 секций), тексты-фолбэки на случай отключённого JS
css/style.css   — вся вёрстка и дизайн-система (тёмная тема, акцент через --accent)
js/config.js    — ЕДИНСТВЕННЫЙ файл для переделки под клиента
js/main.js      — рендер контента из config.js + интерактив
404.html        — страница «не найдено» в стиле сайта
netlify.toml    — настройки Netlify (сборки нет, папка публикуется как есть)
netlify/functions/lead.mjs — заявки с формы -> Telegram (для Netlify)
api/lead.php    — то же для обычного PHP-хостинга (Timeweb, Beget, REG.RU…)
NEW_CLIENT.md   — пошаговая инструкция «новый клиент -> готовый сайт»
README.md       — этот файл
```

> **Новый заказ?** Начните с [`NEW_CLIENT.md`](NEW_CLIENT.md).

## Быстрый старт

1. Откройте `index.html` в браузере — или запустите локальный сервер:
   ```bash
   python3 -m http.server 8000
   # затем http://localhost:8000
   ```
2. Всё работает сразу: контент, форма (заглушка), анимации.

## Переделка под клиента (~15 минут)

Откройте `js/config.js` и поменяйте:

1. **`brand`** — название, описание, копирайт и **`accentColor`** (одна строка перекрашивает весь сайт: кнопки, акценты, свечения).
2. **`hero`** — бейдж, рейтинг (`rating`, `ratingNote`), заголовок (в HTML-разметке можно расставить `<span class="accent">` для оранжевых акцентных фраз), подзаголовок, фото, пункты списка.
3. **`stats`** — цифры для анимированных счётчиков.
4. **`services`** — услуги, иконки (`settings`, `activity`, `tool`, `disc`, `drop`, `paint`), цены.
5. **`advantages`** — преимущества (иконки: `shield`, `clipboard`, `clock`, `car`).
6. **`process`** — шаги работы.
7. **`gallery`** — фото работ (сейчас Unsplash-заглушки — замените на реальные фото клиента).
8. **`pricing`** — прайс и примечание с акцией (поддерживает HTML).
9. **`reviews`** — отзывы.
10. **`faq`** — частые вопросы.
11. **`contacts`** — телефон (`phone` + `phoneHref`), адрес, часы, почта, WhatsApp, Telegram, карта и **`privacyUrl`** — ссылка на политику конфиденциальности (сейчас заглушка `#`, перед запуском обязательно заменить).
12. **`socials`** — соцсети (иконки: `telegram`, `whatsapp`, `vk`, `youtube`).

В `index.html` трогать ничего не нужно — все тексты, телефоны и ссылки подставляются из конфига по атрибутам `data-cfg`, `data-cfg-html`, `data-cfg-src`, `data-cfg-tel`, `data-cfg-tel-btn`, `data-cfg-href`, а списки/карточки рендерятся в слоты `data-render`.

## Форма заявки

В `config.js` поле **`formEndpoint`**:

- `null` — режим заглушки: показывается сообщение об успехе, данные никуда не отправляются (удобно для демо и портфолио);
- `"https://formspree.io/f/xxxxxxx"` — реальная отправка заявок на почту через Formspree (регистрация бесплатная, endpoint берётся из настроек формы);
- `"/api/lead"` — заявки в Telegram, сайт на Netlify (`netlify/functions/lead.mjs`);
- `"/api/lead.php"` — заявки в Telegram, обычный PHP-хостинг (`api/lead.php`).

Настройка бота и переменных — в [`NEW_CLIENT.md`](NEW_CLIENT.md), раздел 4. Заявки нигде не сохраняются, только пересылаются. Скрытое поле-ловушка отсекает простых спам-ботов.

Форма сама: маска телефона, валидация с подсветкой ошибок (включая обязательное согласие на обработку данных), спиннер загрузки, экран «Заявка отправлена!» с кнопкой повторной отправки, а при сбое — сообщение с телефоном прямо в форме.

## Секции лендинга

Шапка (sticky, burger на мобильных) → Hero с параллакс-картинкой и плавающими карточками → счётчики → преимущества → услуги → 4 шага процесса → галерея с лайтбоксом → прайс в виде «чека» → отзывы → FAQ-аккордеон → форма записи с контактами → футер + плавающая кнопка звонка.

## Технические особенности

- **Адаптив**: брейкпоинты 1100 / 960 / 640 px, мобильное меню-шторка.
- **Анимации**: появление блоков при скролле (IntersectionObserver) со стаггером, счётчики, свечение карточек по курсору, hover-эффекты. Уважается `prefers-reduced-motion`.
- **Доступность**: aria-атрибуты у меню, аккордеона и формы, видимый фокус, alt у изображений.
- **Без JS**: тексты остаются видимыми (контент-фолбэки прямо в HTML), страница остаётся осмысленной.
- **Браузеры**: современные (используется `color-mix()`, CSS-переменные, `aspect-ratio`).
